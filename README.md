# Iran Prosperity Project RAG Assistant

A Retrieval-Augmented Generation (RAG) QA assistant over IPP documents related to Reza Pahlavi’s transition plan, returning citation-grounded answers.

## How to run (Colab)
1) Build the index: `notebooks/build_index.ipynb`  
2) Ask questions: `notebooks/chat.ipynb`

> The vector index is generated locally and is not stored in this repo.
